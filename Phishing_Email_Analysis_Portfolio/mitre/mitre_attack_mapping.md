# MITRE ATT&CK Mapping

> Portfolio lab: mappings are based on the simulated evidence in this project.

| Technique | ID | Evidence |
|---|---|---|
| Phishing | T1566 | Email attempts to socially engineer the recipient. |
| Spearphishing Link | T1566.002 | Message contains a simulated credential-verification link. |
| Spearphishing Attachment | T1566.001 | Message includes an unexpected ZIP attachment. |

## Analyst note
Only map techniques supported by observable evidence. Do not claim execution, persistence, credential theft, or command-and-control unless telemetry proves those behaviours.
